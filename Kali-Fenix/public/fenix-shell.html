01 / ESCOLHA O DESTINO

Onde instalar o shell?

Selecione o ambiente para ver os requisitos, os comandos correspondentes e a forma de acesso.

O que é o ttyd?

É um projeto open source (MIT) que publica um terminal no navegador usando WebSockets. O processo roda na máquina escolhida; a página do Kali Fenix não executa comandos por conta própria.

03 / SEGURANÇA E LIMITES DO NAVEGADOR

O navegador não instala sistemas operacionais.

O Kali Fenix é o painel de escolha e documentação. A instalação é realizada no destino que você selecionar, com permissão administrativa nesse dispositivo ou servidor.

Computador localVocê executa o instalador no Windows, Linux ou Kali. O shell abre em localhost.
Pendrive Kali LiveÉ necessário criar a mídia inicializável em outra ferramenta. A gravação apaga o pendrive; persistência exige particionamento adicional.
VPSO serviço fica ligado à interface local e só é acessado via túnel SSH ou proxy reverso autenticado.
Cloud ShellÉ um ambiente de desenvolvimento temporário, não substitui uma VPS nem deve ser usado para varredura de rede.
