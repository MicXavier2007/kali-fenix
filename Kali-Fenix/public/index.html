02 / FENIX TOOL MANAGER

Inventário da estação.

Importe um inventário gerado em uma máquina Kali ou Debian para comparar pacotes instalados com o catálogo. O arquivo é processado localmente no navegador e não é enviado ao servidor.

Como gerar o inventário no Kali

Execute o comando abaixo no sistema que deseja conferir. Depois selecione o arquivo fenix-inventory.tsv.

dpkg-query -W -f='${binary:Package}\t${Version}\n' > fenix-inventory.tsv
Nenhum inventário importado.
O inventário aparecerá aqui após a importação.

A correspondência usa nomes de pacotes conhecidos. “Não localizado” não prova que a ferramenta esteja ausente: alguns programas usam nomes de pacotes diferentes ou não são distribuídos via APT. A consulta nunca instala nem executa ferramentas.

04 / REMOTE WORKSTATION

Estação Kali remota.

Use o desktop e o terminal reais de uma máquina Kali Rolling. A sessão é servida por uma infraestrutura externa; a Netlify mantém somente o portal e o redirecionamento.

Portal de acesso KaliRequer VPS/VM e Guacamole configurados

Quando a infraestrutura estiver pronta, entre no portal remoto para abrir sua sessão. O terminal e os programas são executados na VM, não no seu notebook.

SistemaKali Linux Rolling
Ambiente gráficoXFCE
TerminalBash / SSH
Acesso webApache Guacamole
Abrir estação Kali no navegador ↗ Abrir página Fenix Shell ↗

O link só abrirá uma sessão depois que FENIX_KALI_PORTAL_URL estiver configurada na Netlify.

INFRAESTRUTURA NECESSÁRIA

O que precisa existir no servidor.

  1. Uma VM/VPS compatível com Kali Linux, com armazenamento e memória suficientes.
  2. Kali Rolling instalado e atualizado, com os pacotes escolhidos para o trabalho.
  3. XFCE, SSH e XRDP instalados na VM.
  4. Apache Guacamole com autenticação individual, HTTPS e MFA.
  5. Conexão privada entre Guacamole e VM, além de regras de rede administradas.
Importante: Netlify não hospeda uma VM Linux. Este site não simula um terminal; ele encaminha para a estação real quando ela estiver implantada.
